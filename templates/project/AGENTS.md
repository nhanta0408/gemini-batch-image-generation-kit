# Image project (data only)

This folder holds prompts and pictures for the Gemini Batch Image Generation Tool. The tool and its agent
instructions live at `{{TOOL_ROOT}}`: read `{{TOOL_ROOT}}/AGENTS.md` and run `./gbig` from there
(`./gbig use <this project's name>` selects it). Do not edit `manifest.json`, `jobs/`, or the auto section of
`memory.md`.

# Image project

Made with the Gemini Batch Image Generation Tool at `{{TOOL_ROOT}}`.
Run commands and open the AI assistant **in the tool folder**; its `AGENTS.md` explains everything.
Dashboard: double-click `Open Dashboard.command` in the tool folder, or run `./gbig open` there.

- `batches/<batch>/prompts.csv`: the picture ideas. `batches/<batch>/images/`: the pictures (`images/legacy/`: earlier drawings).
- `memory.md`: notes, plus what each job produced and whether each file is still the original (MD5).
- `manifest.json` and `jobs/` are written by the tool: do not edit them by hand.
